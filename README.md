# SQL Projects — Warehouse and Analytics
This repository contains two separate, related projects kept intentionally distinct:

- `sql-data-warehouse-project`: an end-to-end Sales Data Warehouse (ETL, data models, DDL and transformations).
- `sql-data-analytics-project`: SQL-based analysis and reporting scripts that run on top of the warehouse (exploration, measures, reports).

Keep the projects separate so the engineering (warehouse) work and the analytics/reporting work remain modular and reproducible.

See the subfolder READMEs for details on running each project.

Quick links:

- Warehouse: [sql-data-warehouse-project](sql-data-warehouse-project/README.md)
- Analytics: [sql-data-analytics-project](sql-data-analytics-project/README.md)

Datasets for both projects: `sql-data-warehouse-project/datasets/` and `sql-data-analytics-project/datasets/`.

If you're presenting this as two deliverables (Data Warehouse and Data Analytics), keep code, documentation, and deliverables (report, slides) for each project inside their respective folders.
